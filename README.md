# ✨ Overview

Finora is a clean, modern and user-centric Personal Finance Tracker designed to simplify money management.

The application enables users to record transactions, monitor spending patterns, analyze financial behavior, and work towards savings goals through a visually engaging dashboard.

Rather than focusing only on functionality, the project emphasizes:

- Clean User Experience
- Product Thinking
- Responsive Design
- Data Visualization
- Financial Awareness
